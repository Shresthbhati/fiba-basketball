# Tactical Analysis, Optical Tracking & Evaluated ML (Phase 7, Spec §7.2–§7.5, §12, ADR-0016)

## Overview & AI Safety Principles
Phase 7 introduces machine-learning assisted tactical event detection, vector trajectory embeddings for play similarity, Level 3 rule-based defensive coverage simulations, and an audited model registry.
- **Mandatory Human-in-the-Loop Review**: Candidate events generated by optical tracking detectors enter in status `CANDIDATE` and are never added to official box scores or team statistics until explicitly confirmed by a coach (`CONFIRMED` or `ADJUSTED`).
- **No Black-Box Predictive Claims (ADR-0007)**: All scenario simulations are rule-based schematic explorations and must carry the prominent disclaimer:
  *"Level 3 Rule-Based Scenario Simulation — tactical schematic illustration, not an empirical outcome prediction."*
- **Model Governance & Instant Rollback**: Models are benchmarked on held-out datasets ($F_1$, precision, recall) and can be atomically rolled back if accuracy drift is observed.
- **Negative AuthZ (ADR-0010)**: All candidate events, similarity matching, and scenario simulations are private to authorized team coaching staff; unauthorized cross-team requests return RFC 9457 `404 Not Found`.

## Data Model

### `tactical_candidate_events`
- `id`: UUIDv7 PK.
- `game_id`: UUID references `film_games.id` (cascading delete).
- `clip_id`: UUID references `film_clips.id` (optional).
- `team_id`: UUID references `teams.id` (cascading delete).
- `event_type`: Text (`PICK_AND_ROLL | POP | SCREEN_AWAY | DRIVE_AND_KICK | CUT_TO_RIM | ISOLATION | POST_UP | TRANSITION_BREAK`).
- `timestamp_seconds`: Real (exact offset in match video).
- `court_coordinates`: JSONB `{ x: number, y: number, endX?: number, endY?: number }` in FIBA meters (origin center court).
- `involved_player_ids`: JSONB array of player UUIDs.
- `confidence_score`: Real (0.0 to 1.0).
- `status`: Text (`CANDIDATE | CONFIRMED | REJECTED | ADJUSTED`).
- `reviewed_by_id`: UUID references `users.id` (optional).
- `reviewed_at`: Timestamp with timezone (optional).
- `review_notes`: Text (optional).
- `model_version`: Text (e.g. `v1.2.0`).
- `created_at`: Timestamp with timezone.
- `updated_at`: Timestamp with timezone.

### `play_similarity_embeddings`
- `id`: UUIDv7 PK.
- `play_id`: UUID references `tactical_plays.id` (cascading delete).
- `team_id`: UUID references `teams.id` (cascading delete).
- `embedding_vector`: JSONB (8-dimensional L2-normalized spatial feature vector).
- `spatial_features`: JSONB `{ primaryAction, startQuadrant, endQuadrant, passCount, screenCount, trajectoryLengthMeters }`.
- `model_version`: Text.
- `created_at`: Timestamp with timezone.
- `updated_at`: Timestamp with timezone.

### `scenario_simulations`
- `id`: UUIDv7 PK.
- `team_id`: UUID references `teams.id` (cascading delete).
- `play_id`: UUID references `tactical_plays.id` (optional).
- `title`: Text.
- `coverage_type`: Text (`DROP | SWITCH | BLITZ_TRAP | HEDGE_AND_RECOVER | ICE_WEAK | HELP_AND_RECOVER`).
- `simulation_level`: Integer (3).
- `offensive_setup`: JSONB.
- `defensive_response`: JSONB.
- `coverage_metrics`: JSONB `{ spaceAdvantageScore, contestedShotRisk, openLaneCount, secondaryHelpDelaySec }`.
- `tactical_analysis`: Text.
- `disclaimer`: Text.
- `created_by_id`: UUID references `users.id` (cascading delete).
- `created_at`: Timestamp with timezone.

### `tactical_model_registry`
- `id`: UUIDv7 PK.
- `model_version`: Text (unique).
- `model_type`: Text (`CV_TRACKING | TACTICAL_CANDIDATE | PLAY_EMBEDDING | COVERAGE_SIMULATOR`).
- `benchmark_dataset`: Text.
- `metrics`: JSONB `{ accuracy, f1Score, precision, recall, sampleSize }`.
- `status`: Text (`CANDIDATE | ACTIVE | DEPRECATED | ROLLED_BACK`).
- `active_since`: Timestamp with timezone.
- `rolled_back_at`: Timestamp with timezone.
- `rollback_reason`: Text.
- `created_at`: Timestamp with timezone.
- `updated_at`: Timestamp with timezone.

## API Endpoints

- `POST /api/v1/tactical/candidates`: Ingest candidate tracking detection.
- `GET /api/v1/tactical/teams/:teamId/candidates`: List team candidate review queue with filters.
- `PATCH /api/v1/tactical/candidates/:id/review`: Review, confirm, adjust, or reject candidate.
- `POST /api/v1/tactical/plays/:playId/embeddings`: Generate or refresh spatial trajectory embedding.
- `GET /api/v1/tactical/plays/:playId/similar`: Query similar plays using vector cosine distance.
- `POST /api/v1/tactical/simulations`: Execute Level 3 defensive coverage simulation.
- `GET /api/v1/tactical/simulations/:id`: Get simulation results and tactical breakdown.
- `GET /api/v1/tactical/teams/:teamId/simulations`: List team simulations.
- `POST /api/v1/tactical/models`: Register model with evaluation metrics.
- `GET /api/v1/tactical/models`: List cataloged models.
- `POST /api/v1/tactical/models/:modelVersion/promote`: Promote model to production ACTIVE.
- `POST /api/v1/tactical/models/:modelVersion/rollback`: Atomic rollback to previous benchmarked model.
