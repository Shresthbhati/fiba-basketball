# ADR-0006: Computer-vision scope v1

Status: Accepted (provisional)

## Decision
MediaPipe Pose Landmarker. v1 supports exactly two protocols: bodyweight squat (side view) and countermovement jump (side view, labelled "estimate"). Abstain below the confidence threshold. Release-gate thresholds are defined in a follow-up ADR before the flag is enabled for non-dev users.
