# ADR-0012: Drizzle + Postgres sessions

Status: Accepted

- Data access: Drizzle ORM; schema in `services/api/src/db/schema.ts`; SQL migrations generated by `drizzle-kit generate` into `services/api/drizzle/` and applied on API start.
- Tests run against embedded Postgres (PGlite), so no Docker is needed for `pnpm test`. PostGIS-dependent tests (courts) will need the compose Postgres and run in CI with a service container.
- Sessions live in the Postgres `sessions` table (token stored as SHA-256 hash) instead of Redis, to cut a moving part for v1. Redis stays optional for rate limits/cache later (amends ADR-0010).
- CSRF: SameSite=Lax cookie + Origin-must-match-Host check on mutating requests.
- Passwords: Argon2id (`@node-rs/argon2`). Under-13 signup rejected; 13–17 flagged `isMinor`.
